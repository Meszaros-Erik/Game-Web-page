## Web Gemes
**Web Gemes** is a curated collection of lightweight, interactive web-based games and mini-apps. This repository serves as a digital playground featuring classic logic puzzles, arcade staples, and fun utility tools built with web technologies.
### What's Inside?
- **2048 Game :** The addictive tile-merging challenge.
- **Snake Game :** A tribute to the legendary Nokia-era classic.
- **Mine Sweeper :** A strategic battle against hidden explosives.
- **Lottery Spin Wheel & Roll Dice :** Interactive tools for games of chance and quick decision-making.  
Whether you're looking for a quick distraction or exploring simple game logic, these ==gems== are polished and ready to play directly in your browser.
